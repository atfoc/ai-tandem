# W2: this computer's section: choices inside the contracts, and what the integration has to know

No contract of section 3 was left unmet. Where the plan leaves a detail open, W2 took these:

- **This computer's tree is `State.connected`.** The page holds it from the entry's `snapshot` until the entry leaves `connected` (or the
  transport's stream is closed for good), as it holds a remote server's from its snapshot (`sections[id]`). Neither the `hello` nor the
  state `connected` sets it: the snapshot comes first (C3.4). `reachable`, `serverConnected`, `leftBehind`, `saveOutage`, `boardView`,
  `remoteView` and `goneBySend` lost their "is it a section" argument: every thing is judged by its own server's tree.
- **A thing of this computer that is on screen and not in its snapshot stays, marked gone** (`applySnapshot`), as a section's does. A
  `chat_removed` / `board_removed` event of this computer, though, still removes the thing at once (the user deleting it in this window
  must not leave "no longer on This computer"); only a section's is kept gone.
- **A chat of this computer with a draft the browser keeps is not left behind while this computer is away** (`leftBehind(…, kept)`):
  `saveDraft` takes a chat the page no longer has for deleted and says "saved", which would drop the copy.
- **`not_started` and every other failing state of this computer's entry** offer Retry (`owner.retry`) and, in the app, "Open server log":
  the plan names `not_started` only, J1's `owner.retry` works in every waiting state (J1 deviation 9).
- **The restart flow has no "missing" banner** (W1's interim had one for a program that is gone): the app's reason is shown as it is. `State.update`
  became `State.restart` (`idle`, `restarting`, `failed` with the reason); `logic/version.ts` keeps only `runningChats` and `restartConfirmText`
  (`bannerFor`, `UpdateBanner` and the × of the banner went).
- **The "+" of the sidebar's head and the Home screen's buttons are disabled** while this computer's server is not connected; the Home screen
  says so instead of the agents sentence (what agents it has is not known then).
- **"New group" under the local tree went**: the sidebar is sections only, a section's "+" makes a group.
- **`prunedLocalGroups` takes the server list**, so a collapse key that is an entry id is never taken for a group of this computer. The mock's
  ids (`s_studio`, `s_away`) are not of the form `s_` + 12 hex that W1's test of the key relied on; a real id is.
- **`LOCAL_ENTRY` starts `connecting`** (the page has had no word of this computer's server yet).
- **`web/package.json`**: `dev/hostface.test.mjs` is in the `test` script (M1's note).
