# M1 deviations and open points

Deviations from `plans/app-as-client-plan.md` (C5), each with the reason.

- **The face checks who asks (`hostface.mjs`).** C5.1 lists no such check. The face answers 403 `bad_host` to a request whose
  `Host` is not a loopback name (`127.0.0.1`, `localhost`, `[::1]`, any port) or whose `Origin` is not its own host, and the
  mock's `/mock/*` controls (which run code) do the same. The host holds secrets and passes calls on; without the check any
  site open in the same browser could use it, or a rebound DNS name could. `ownRequest(req)` is exported for `host.mjs` (H1).
- **Three additions to the face's surface** that tests need: the option `pingMs` (the stream's ping, 20 s by default) and
  `bodyMax` (160 MiB by default, above the 128 MiB scene limit the client checks itself), and `face.drop()` (cuts the
  stream's connection; the mock's `dropStreams()` uses it). `host.mjs` may ignore all three.
- **The mock has no `GET /api/hello`.** The checks' driver found its mock by the pid in that answer; it reads
  `GET /mock/state` (`{pid, subscribed, streams}`) now (`dev/shot.mjs` `startMock`). `/mock/state` no longer lists `clients`.
- **`flags.hello.version`** is also the version this computer's entry shows (`ServerView.version`), so the page's A24
  comparison (the page's build against the local entry's version) can be driven as the update notice was. `webVersion` is gone.
- **`addServer(entry, { tree: false })` and `setServerState(id, "connected", { tree: false })`** make the entry `connecting`: the
  contract has no "connected, snapshot not read yet". `sectionFirst` is ignored (the order is fixed by C3.4). `flags.retake`
  and the 503 `not_held_there` went with the relay (the page takes its boards again itself after `hello`).
- **A client API refuses a `server` in the body of a make, whatever its value** (`server_refused`, "an API client cannot name a
  server": internal/server/apiclient.go), so `{server: "local"}` is refused too, and `DELETE …?local=1` is an ordinary delete.
  The relay's `replace_refused` and `no_record` are gone. A PATCH of a group with `collapsed` is `collapsed_refused` on every
  server, this computer's included (C1.5).
- **No group in a snapshot or a `groups` event has `collapsed`** (C1.5); the seeds still write `collapsed: true` into their
  groups, which is now ignored. Checks and shots that needed a closed group of this computer read it from the page's storage
  (`aiwb.collapsed`, by the group's key): `dev/readme-shots.mjs` does so for the "remote-servers" shot.
- **App operations the contract leaves to the module are made up by the mock** (C3.10 answers, no module behind them):
  `servers.*` keep a list in memory (an added server is `connecting` and connected 30 ms later; the form's secret is never kept
  or told), `owner.restart` / `owner.retry` / `owner.status` follow `flags.restart`, `flags.start`, `flags.mcp` (documented in
  the header of `mock.mjs`), `owner.openLog` and `owner.reveal` answer 501 `not_here`.

Checks changed beyond a path (the assertion went with a removed behaviour). W2 owns their replacement:

- `SEC.7-drop.mjs`: the block on a save answered 503 `not_held_there` while this computer's server took the board again is
  removed. The page takes its boards again after `hello`; a check of that is W2's.
- `SEC.2-states.mjs`: "the tree before the state" (either order of the two events) is removed; the order is fixed.
- `P0.4-routes.mjs`: the section's routes block is rewritten to the client API (a call names its server; `not_client_api`;
  the order of `hello`, `snapshot`, `server_state`). It reads the stream at `/host/events`.

Left for W2 / integration (assertions of the page, which I could not run: W1's page was not available to me):

- `SEC.3-notagroup.mjs` still expects a PATCH `/api/groups/g_shop {collapsed: true}` for this computer's group; the collapse of
  every group is the page's storage now (A15).
- `A1.5-notices.mjs` and the `update-restart`, `update-reload` and `stream-down` states of `mock-ui.js`: there is no "reload"
  notice (one build); a stream closed for good is a 503 on `/host/events` while `flags.streamDown` is set (A25); `dropStreams()`
  alone cuts the connection and the page's stream starts over.
- None of the browser checks was run against a page: `npm run uicheck` needs the page of W1. `node --check` passes on every
  script of `web/dev`. `P0.4-routes.mjs` was run up to its page parts (which need W1's page); everything before them passes.
- `web/dev/reallibrary.mjs` (starts real Go servers, uses the old API) is H1's. `web/package.json` is untouched: W2 adds
  `dev/hostface.test.mjs` to the `test` script.
