# W1: the page's transport: choices inside the contracts, and what the integration has to know

No contract (C6, and the page's side of C3.4/C4/C5) was left unmet. Where the plan leaves a detail open, W1 took these:

- **A stream closed for good (A25).** The page marks every entry `connecting` (not `unreachable`), drops the trees of the sections,
  marks the libraries not connected, and calls `stream()` again after 1 s (`conn.waits.reopenMs`, lowered by tests).
  `onState("open")` changes nothing in the page: the greeting (`hello`, `snapshot`, `server_state`) does.
- **The HTTP way's `app()`** is a `POST /host/app/<op>` (C5.1) with the arguments as a JSON body, none when there are none
  (C6.2 writes `fetch("/host/app/<op>")` without the method).
- **Selection saved before a reload.** This computer's snapshot judges the selection of this computer's things only; a section's
  tree judges its own (`validSelOn`), so the selection of a section's thing survives until that server's tree comes.
  `dropServer` clears a selection of an entry that left the list.
- **A library's notice** (`libraryNotice` of a snapshot) is kept per server in `conn.ts` and put on the library built from
  the `own_library` events that follow (the event carries none).
- **`Group.collapsed` is gone from the page's types**, and `groupIn` no longer strips it. `store.collapsed` holds the collapse of
  every group and of every section, `local` included (key `local`); a bare key that looks like an entry id (`s_` + 12 hex) is a
  section, any other bare key is a group of this computer, judged by this computer's snapshot (`prunedLocalGroups`).
- **`State.dataDir`, `Snapshot.dataDir`, `api.state/hello/restart/collapseGroup`, `libraryApi.read`, `clientId`, `logic/unknownclient.ts`,
  the `reload` banner and `listsFrom` were removed.** The banner is now only `restart` (A24, interim: W2 replaces it).
- **`web/build.mjs` writes no `version.json`.** `cmd/ai-whiteboard/scripts_test.go:727` still lists `version.json` among the files of a
  server folder (G2/integration).
- **`main.tsx`** shows a fixed line ("AI Whiteboard runs in its app.") when the page has no way (not in the app, not loaded over http).
