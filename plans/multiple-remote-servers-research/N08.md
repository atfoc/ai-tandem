# N08: Listening on the wildcard address, port conflicts, and loading a certificate with its key

One Go program, standard library only, was run outside the repository on macOS (darwin/arm64, Go 1.25.1).
It listens on `0.0.0.0` with ephemeral ports, provokes port conflicts, loads good and bad certificate and
key files, and serves HTTPS on a wildcard listener. Nothing of the app was started.

**What the run showed.** `net.Listen("tcp","0.0.0.0:0")` gives a dual-stack listener that reports `[::]:<port>`
and is reached through `127.0.0.1` and `[::1]`; with `tcp4` it reports `0.0.0.0:<port>` and `[::1]` is refused.
A second wildcard listen on the same port fails with `bind: address already in use` (EADDRINUSE). A wildcard
listener and a `127.0.0.1` listener on the same port can both be opened, in either order, without error, and
the `127.0.0.1` listener then gets every connection dialed to `127.0.0.1`. An address that is not on the
machine fails with `bind: can't assign requested address` (EADDRNOTAVAIL). `tls.LoadX509KeyPair` returns an
error for a pair that does not match, a missing file and an empty file. `http.Server.ServeTLS` returns that
same error at once, before any connection, and leaves the listener open.

**Differences from the predictions.** The five predicted results were all observed again; none differs.
One result is against what the brief of this report expected, and it is new:

- **Nothing was served through the machine's non-loopback address** (`10.131.67.26`). Every dial to it
  connected, but `Accept` never returned the connection, no byte came back, and the HTTPS request ended in the
  client's time-out. This was so for both networks, in S1, S2 and S5. The macOS application firewall was on,
  and its log shows one queued inbound flow for the program's process per such dial. A system tool (`nc`)
  that listened on `0.0.0.0` in the same minutes was reached through the same address. It follows that the
  firewall held these connections back from the unsigned test program; the run does not show what the Go
  listener does with a non-loopback connection that reaches it.

Marks: **[run]** observed in the output in the appendix, **[side run]** observed with a command next to the
program (quoted where used), **[not run]**.

## S1. Listening on the wildcard address

| `net.Listen` | `Addr()` | dial `127.0.0.1` | dial `[::1]` | dial `10.131.67.26` |
|---|---|---|---|---|
| `("tcp","0.0.0.0:0")` | `[::]:56604` | connected, accepted, answered | connected, accepted, answered | connected, not accepted, no answer in 2 s |
| `("tcp4","0.0.0.0:0")` | `0.0.0.0:56612` | connected, accepted, answered | `connect: connection refused` | connected, not accepted, no answer in 2 s |

- Both calls returned without error and without a measurable delay ("Listen took 0s"). [run]
- With `tcp` the listener is dual stack: `Addr()` is `[::]:<port>`, and a dial to `127.0.0.1` and a dial to
  `[::1]` are both accepted. `Addr().Network()` is `tcp` in both cases. [run]
- With `tcp4` the listener is IPv4 only: `Addr()` is `0.0.0.0:<port>`, `[::1]` is refused. [run]
- Each target was dialed twice: once only to connect, once to read the one byte the listener writes.
  "Accepted" comes from the count of connections `Accept` returned: 4 of 6 dials with `tcp` (the two to
  `10.131.67.26` are missing), 2 of 6 with `tcp4` (two refused, two to `10.131.67.26` missing). [run]
- A dial to `10.131.67.26` returned "connected" within 1 ms, so the TCP connection was made. The
  listener's `Accept` did not return it and the read ended in `i/o timeout` after 2 s. [run]
- Firewall log for the time of the run (`/usr/bin/log show --start ... --end ... --predicate 'process ==
  "socketfilterfw"'`): 17 lines "Handle flow with processPID: 2049", each followed by "Enqueuing new
  inbound flow for <private> with identifier: <private>" and "Enqueuing flow without processing queue".
  The program makes 17 dials to the non-loopback address in one run (4 in S1, 12 in S2, 1 in S5).
  [side run]
- Control with a system tool, same machine, same minutes: `echo hello-from-nc | nc -l 0.0.0.0 <port>` and
  then `nc -w 3 10.131.67.26 <port>` printed `hello-from-nc`. [side run]
- It follows that the firewall, not Go's listener, kept the connections to `10.131.67.26` from being
  accepted. Whether a Go wildcard listener serves a non-loopback connection that the firewall lets through
  was not observed in this run.

## S2. Port conflicts

"W" is the byte the wildcard listener writes, "L" the byte the `127.0.0.1` listener writes. Every dial was
made three times with the same result each time.

| wildcard network | (a) second wildcard listen on the held port | (b) wildcard holds, then `127.0.0.1:<port>` | (c) `127.0.0.1:<port>` holds, then `0.0.0.0:<port>` |
|---|---|---|---|
| `tcp` | error `listen tcp 0.0.0.0:56620: bind: address already in use`, `errors.Is(err, syscall.EADDRINUSE)` true | no error | no error |
| `tcp4` | error `listen tcp4 0.0.0.0:56643: bind: address already in use`, `errors.Is(err, syscall.EADDRINUSE)` true | no error | no error |

When both listeners exist, in (b) and in (c):

| wildcard network | dial `127.0.0.1:<port>` | dial `[::1]:<port>` | dial `10.131.67.26:<port>` |
|---|---|---|---|
| `tcp` | answered by "L" | answered by "W" | connected, no answer, `i/o timeout` |
| `tcp4` | answered by "L" | `connect: connection refused` | connected, no answer, `i/o timeout` |

- (a) A second wildcard listen on a port a wildcard listener holds fails at once, with both networks. The
  error text ends in `bind: address already in use` and `errors.Is(err, syscall.EADDRINUSE)` is true. [run]
- (b) and (c) The second listen returns no error, whichever of the two listeners is opened first, with both
  networks. The process then holds two listeners on one port number. [run]
- A connection dialed to `127.0.0.1:<port>` is accepted by the `127.0.0.1` listener, never by the wildcard
  listener, in (b) and in (c). The order of opening makes no difference. [run]
- With `tcp`, the wildcard listener still accepts what is dialed to `[::1]:<port>`. [run]
- The accept counts agree: with `tcp`, 3 on the wildcard listener (the three `[::1]` dials) and 3 on the
  loopback listener; with `tcp4`, 0 on the wildcard listener and 3 on the loopback listener. [run]
- Which listener accepts a connection dialed to the non-loopback address was **not observed**: all 12 such
  dials connected and none was accepted by either listener (see S1 for the firewall). [run]
- The `127.0.0.1` side was always opened with network `tcp`. The second listen was made by the same process
  as the first; a second process was not tried.

## S3. An address that is not on this machine

## S4. Loading a certificate and its key

The certificate is self-signed, ECDSA P-256, with no DNS name and no IP address in it, written as a
`CERTIFICATE` PEM block. The keys are PKCS #8 in `PRIVATE KEY` PEM blocks. `empty.pem` has 0 bytes.
`missing.pem` does not exist.

| case | `tls.LoadX509KeyPair(certFile, keyFile)` | result |
|---|---|---|
| good pair | `(cert.pem, key.pem)` | no error, one certificate in the chain |
| pair that does not match | `(cert.pem, other-key.pem)` | error `tls: private key does not match public key` |
| missing key file | `(cert.pem, missing.pem)` | error `open <folder>/missing.pem: no such file or directory`, `errors.Is(err, os.ErrNotExist)` true |
| missing certificate file | `(missing.pem, key.pem)` | error `open <folder>/missing.pem: no such file or directory`, `errors.Is(err, os.ErrNotExist)` true |
| empty certificate file | `(empty.pem, key.pem)` | error `tls: failed to find any PEM data in certificate input` |
| empty key file (added) | `(cert.pem, empty.pem)` | error `tls: failed to find any PEM data in key input` |

- All six results are [run]. For the mismatch and the two empty files `errors.Is(err, os.ErrNotExist)` is
  false.
- The error for a missing file names the full path of the file, and it is the same text whether the missing
  file is the certificate or the key; only the path tells them apart. [run]
- Not tried: a file with PEM data of the wrong type, a certificate that has expired, a key file that cannot
  be read because of its mode, an RSA or Ed25519 key.

## S5. Serving HTTPS on the wildcard with that pair

(a) The good pair. An `http.Server` was started with `ServeTLS(listener, "cert.pem", "key.pem")` on a
listener from `net.Listen("tcp","0.0.0.0:0")` (`Addr()` = `[::]:56668`). The client sets
`InsecureSkipVerify` and compares the SHA-256 of the server's certificate with a pinned value in
`VerifyConnection`.

| client | URL | result |
|---|---|---|
| pinned to the certificate's fingerprint | `https://127.0.0.1:<port>/` | status 200, body `hello from 127.0.0.1:56668`, HTTP/1.1 |
| pinned to the certificate's fingerprint | `https://10.131.67.26:<port>/` | error `context deadline exceeded (Client.Timeout exceeded while awaiting headers)` after 5 s |
| pinned to another fingerprint (all zero) | `https://127.0.0.1:<port>/` | error `fingerprint 25cf753613bf4db8 is not the pinned one` (the error of the check itself) |
| Go's default verification, no pin | `https://127.0.0.1:<port>/` | error `tls: failed to verify certificate: x509: certificate signed by unknown authority` |

- `ServeTLS` was still serving 300 ms after the call and had returned no error. [run]
- Through `127.0.0.1` the pinned client got its answer, although the certificate carries no name and no
  address. [run]
- Through the non-loopback address the pinned client got **no answer**: the request ran into the client's
  5 s time-out. This is the same behaviour as the plain connections of S1 and S2, with the same firewall
  state. HTTPS through a non-loopback address is therefore **not verified** by this run. [run]
- A client pinned to another fingerprint is refused by the check, and a client without a pin refuses the
  self-signed certificate. For both the server logged `http: TLS handshake error from 127.0.0.1:<port>:
  remote error: tls: bad certificate`. [run]
- After `Shutdown`, `ServeTLS` returned `http: Server closed`. [run]

(b) Bad pairs. A fresh wildcard listener was opened for each case, `ServeTLS` was called, and no connection
was dialed until it had returned.

| `ServeTLS(listener, certFile, keyFile)` | returned | error |
|---|---|---|
| `(cert.pem, other-key.pem)`, a pair that does not match | at once (under 1 ms), before any connection | `tls: private key does not match public key` |
| `(cert.pem, missing.pem)`, a missing key file | at once (under 1 ms), before any connection | `open <folder>/missing.pem: no such file or directory` |

- `ServeTLS` returns the error at once, before any connection and so before any handshake. The error texts
  are those of `tls.LoadX509KeyPair` in S4. [run]
- `ServeTLS` does not close the listener in this case: a dial to `127.0.0.1:<port>` after the return still
  connected. The caller has to close the listener itself. [run]

// Run: go run main.go   (in an empty folder outside the repository)
package main

import (

	"strconv"

	"syscall"
	"time"

const dialTimeout = 2 * time.Second

var nonLoop string // one non-loopback IPv4 address of this machine, "" if none

func portOf(l net.Listener) string {
	return strconv.Itoa(l.Addr().(*net.TCPAddr).Port)
}

// serveByte answers every connection with one byte and closes it. It counts what Accept returned.
func serveByte(l net.Listener, b byte) *atomic.Int32 {
	n := new(atomic.Int32)
	go func() {
		for {
			c, err := l.Accept()
			if err != nil {
				return
			}
			n.Add(1)
			c.Write([]byte{b})
			c.Close()
		}
	}()
	return n
}

// dial reports "connected" or the error; with read it reports the byte the listener answered.
func dial(addr string, read bool) string {
	start := time.Now()
	c, err := net.DialTimeout("tcp", addr, dialTimeout)
	if err != nil {
		return fmt.Sprintf("error: %v", err)
	}
	defer c.Close()
	if !read {
		return fmt.Sprintf("connected (%s)", time.Since(start).Round(time.Millisecond))
	}
	c.SetReadDeadline(time.Now().Add(dialTimeout))
	buf := make([]byte, 1)
	if _, err := io.ReadFull(c, buf); err != nil {
		return fmt.Sprintf("connected, read error: %v", err)
	}
	return fmt.Sprintf("answered by %q", string(buf))
}

func describe(err error) string {
	if err == nil {
		return "no error"
	}
	return fmt.Sprintf("error %q; EADDRINUSE=%v EADDRNOTAVAIL=%v", err.Error(),
		errors.Is(err, syscall.EADDRINUSE), errors.Is(err, syscall.EADDRNOTAVAIL))
}

func targets(port string) []string {
	t := []string{"127.0.0.1:" + port, "[::1]:" + port}
	if nonLoop != "" {
		t = append(t, nonLoop+":"+port)
	}
	return t
}

func s0() {
	fmt.Println("== S0 set-up")
	fmt.Printf("runtime: %s %s/%s\n", runtime.Version(), runtime.GOOS, runtime.GOARCH)
	addrs, err := net.InterfaceAddrs()
	if err != nil {
		fmt.Printf("InterfaceAddrs: error %v\n", err)
	}
	for _, a := range addrs {
		ipn, ok := a.(*net.IPNet)
		if !ok {
			continue
		}
		ip4 := ipn.IP.To4()
		kind := "skipped"
		switch {
		case ip4 == nil:
			kind = "skipped (IPv6)"
		case ip4.IsLoopback():
			kind = "skipped (loopback)"
		case ip4.IsLinkLocalUnicast():
			kind = "skipped (link-local)"
		case nonLoop == "":
			nonLoop = ip4.String()
			kind = "CHOSEN as the non-loopback IPv4 address"
		default:
			kind = "non-loopback IPv4, not used"
		}
		fmt.Printf("InterfaceAddrs: %s  %s\n", a.String(), kind)
	}
	if nonLoop == "" {
		fmt.Println("non-loopback IPv4: none")
	}
}

func s1() {
	fmt.Println("== S1 listening on the wildcard address")
	for _, network := range []string{"tcp", "tcp4"} {
		start := time.Now()
		l, err := net.Listen(network, "0.0.0.0:0")
		if err != nil {
			fmt.Printf("S1 Listen(%q,\"0.0.0.0:0\"): %s\n", network, describe(err))
			continue
		}
		fmt.Printf("S1 Listen(%q,\"0.0.0.0:0\"): no error, Addr()=%s Network()=%s (Listen took %s)\n",
			network, l.Addr(), l.Addr().Network(), time.Since(start).Round(time.Millisecond))
		n := serveByte(l, 'W')
		for _, t := range targets(portOf(l)) {
			fmt.Printf("S1 %s wildcard, dial %s: %s\n", network, t, dial(t, false))
			fmt.Printf("S1 %s wildcard, dial %s again and read: %s\n", network, t, dial(t, true))
		}
		fmt.Printf("S1 %s wildcard: %d dials were made, Accept returned %d connections\n", network, 2*len(targets(portOf(l))), n.Load())
		l.Close()
	}
}

func s2() {
	fmt.Println("== S2 port conflicts")
	for _, network := range []string{"tcp", "tcp4"} {
		// (a) wildcard, then wildcard again on the same port.
		w, err := net.Listen(network, "0.0.0.0:0")

			fmt.Printf("S2a %s: first listen: %s\n", network, describe(err))

		}

			w2.Close()
		}

func writePEM(path, typ string, der []byte) {
	if err := os.WriteFile(path, pem.EncodeToMemory(&pem.Block{Type: typ, Bytes: der}), 0o600); err != nil {
		panic(err)
	}
}

func newKey(path string) *ecdsa.PrivateKey {
	k, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
	if err != nil {
		panic(err)
	}
	der, err := x509.MarshalPKCS8PrivateKey(k)
	if err != nil {
		panic(err)
	}
	writePEM(path, "PRIVATE KEY", der)
	return k
}

// s4 returns the paths of the certificate, its key, the second key, a missing file, and the fingerprint.
func s4(dir string) (cert, key, otherKey, missing string, fp [32]byte) {
	fmt.Println("== S4 loading a certificate and its key")
	cert = filepath.Join(dir, "cert.pem")
	key = filepath.Join(dir, "key.pem")
	otherKey = filepath.Join(dir, "other-key.pem")
	missing = filepath.Join(dir, "missing.pem")
	empty := filepath.Join(dir, "empty.pem")

	k := newKey(key)
	newKey(otherKey)
	tmpl := &x509.Certificate{
		SerialNumber: big.NewInt(1),
		Subject:      pkix.Name{CommonName: "n08-check"},
		NotBefore:    time.Now().Add(-time.Hour),
		NotAfter:     time.Now().Add(24 * time.Hour),
		KeyUsage:     x509.KeyUsageDigitalSignature,
		ExtKeyUsage:  []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth},
	}
	der, err := x509.CreateCertificate(rand.Reader, tmpl, tmpl, &k.PublicKey, k)
	if err != nil {
		panic(err)
	}
	writePEM(cert, "CERTIFICATE", der)
	if err := os.WriteFile(empty, nil, 0o600); err != nil {
		panic(err)
	}
	fp = sha256.Sum256(der)
	fmt.Printf("S4 made cert.pem (self-signed, ECDSA P-256, no names), key.pem, other-key.pem, empty.pem (0 bytes); missing.pem does not exist\n")

	load := func(label, c, k string) {

// pinned returns a client that accepts exactly the certificate with this SHA-256 fingerprint.
func pinned(fp [32]byte) *http.Client {
	return &http.Client{
		Timeout: 5 * time.Second,
		Transport: &http.Transport{
			DisableKeepAlives: true,
			TLSClientConfig: &tls.Config{
				InsecureSkipVerify: true,
				VerifyConnection: func(cs tls.ConnectionState) error {
					if len(cs.PeerCertificates) == 0 {
						return errors.New("no certificate")
					}
					got := sha256.Sum256(cs.PeerCertificates[0].Raw)
					if got != fp {
						return fmt.Errorf("fingerprint %s is not the pinned one", hex.EncodeToString(got[:8]))
					}
					return nil
				},
			},
		},
	}
}

func get(c *http.Client, url string) string {
	resp, err := c.Get(url)
	if err != nil {
		return fmt.Sprintf("error: %v", err)
	}
	defer resp.Body.Close()
	body, _ := io.ReadAll(resp.Body)
	return fmt.Sprintf("status %d, body %q, %s", resp.StatusCode, string(body), resp.Proto)
}
