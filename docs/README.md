# Documentation

Reference pages for AI Whiteboard. The [main README](../README.md) is the short overview; these pages hold the detail.

- [Architecture](architecture.md): how the server, the web client and the desktop app fit together, the MCP listener and board tools, subagent settings, `get_image`, images in a message, and pi.
- [Prompt library](prompt-library.md): the prompt library's popups, search, rules, storage, use with several servers, and its routes.
- [Remote servers](remote-servers.md): building the server for another machine, setting it up, and using it from the app: chats, whiteboards, feature levels and the remote port.
- [Server commands and flags](server-reference.md): the `ai-whiteboard` commands, the remote commands and the server flags.
- [Troubleshooting the board MCP](troubleshooting.md): checking the listener, probing the endpoint, the server log, Cursor showing no board tools, and port 6006 being taken.
- [Limitations](limitations.md): what the app does not do, and the caps on running chats.
- [Build and develop](development.md): prerequisites, running the app in the browser or as the desktop app, building the macOS app, and the tests.
- [Concurrent branches, phase 0](concurrent-branches-phase0.md): the notes of the first phase of concurrent branches.
